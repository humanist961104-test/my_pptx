# 브랜드 디자인 가이드라인 (Red Pitch Deck 스타일)

> 출처: 사용자가 제공한 "Coca-Cola Investor Pitch Presentation" 슬라이드 모음 이미지(표지 1장 + 내지 약 30장).
> 이미지가 축소본이라 **색상값은 눈으로 추정한 값**이고, 글꼴은 이미지에서 식별한 인상 기준입니다. 정확한 브랜드 값이 있으면 이 문서의 토큰만 바꾸면 됩니다.
> 이 문서는 `skills/pptx/SKILL.md`의 일반 디자인 조언보다 **우선**합니다 (충돌 정리는 맨 아래 "스킬 기본 규칙과의 관계" 참고).

---

## 1. 한 줄 요약

**"빨강이 지배하고, 흰 여백이 숨 쉬고, 검정이 잡아주는" 제품 사진 중심 투자자 발표 덱.**
표지와 섹션 전환·마무리는 전면 빨강, 내지는 흰 바탕에 빨간 블록 포인트를 쓴다.

비율 목표: **빨강 40% · 흰색 45% · 검정/회색 10% · 사진 및 기타 5%** (덱 전체 기준).

---

## 2. 색상 토큰

pptxgenjs에서는 `#` 없이 6자리 hex만 쓴다 (알파 8자리 금지).

| 토큰 | Hex | 용도 |
|------|-----|------|
| `RED` | `F40009` | 주색. 표지·섹션 배경, 타이틀 강조, 코너 블록, 통계 바, 차트 1번 계열 |
| `RED_DEEP` | `B30000` | 빨강 위의 그림자·보조 블록, 차트 2번 계열 |
| `RED_TINT` | `FDECEC` | 카드·표 배경 (흰 바탕 위 은은한 구분) |
| `WHITE` | `FFFFFF` | 내지 배경, 빨강 배경 위 텍스트 |
| `BLACK` | `111111` | 본문 제목, 작은 블록·× 마커, 대비 포인트 |
| `GRAY_TEXT` | `5F5F5F` | 흰 배경 본문 |
| `GRAY_LIGHT` | `F2F2F2` | 표 줄무늬, 보조 패널 |
| `GRAY_LINE` | `D9D9D9` | 구분선, 점선 |

규칙
- 한 슬라이드에서 **빨강은 "주인공 1곳"** 에 집중 (큰 블록 1개 또는 배경 전체). 여기저기 흩뿌리지 않는다.
- 빨강 배경 위 텍스트는 **흰색만**. 빨강 위에 검정·회색 본문 금지.
- 흰 배경 위 본문은 `BLACK` 또는 `GRAY_TEXT`, 강조 단어만 `RED`.
- 파랑·초록·보라 등 다른 색상 사용 금지. 차트에서 구분이 더 필요하면 `BLACK`, `GRAY_TEXT`, `GRAY_LINE` 순으로 쓴다.

## 3. 타이포그래피

| 요소 | 크기 | 굵기 | 색 |
|------|------|------|-----|
| 표지 메인 타이틀 | 54–60pt | Bold | 흰색 (빨강 배경) |
| 표지 서브타이틀 | 16–18pt | Regular(가는 느낌) | 흰색 |
| 슬라이드 제목 | 28–32pt | Bold | 흰 배경: `RED` 또는 `BLACK` / 빨강 배경: 흰색 |
| 소제목 | 16–20pt | Bold | `BLACK` (흰 배경) |
| 본문 | 12–14pt (최소 11pt) | Regular | `GRAY_TEXT` |
| 큰 수치(통계 바) | 30–40pt | Bold | 흰색 (빨강 바 위) |
| 캡션·출처 | 10pt | Regular | `GRAY_TEXT` |

글꼴
- **한글: `Malgun Gothic`** (Windows PowerPoint 기본 탑재, 제목·본문 공통).
- **영문/숫자 전용 텍스트: `Arial`** 또는 `Calibri` (안전 글꼴).
- 참고 이미지의 표지 로고·"Thank You," 는 필기체(스크립트) 로고 서체다. **필기체는 영문 짧은 문구(표지 한 단어, "Thank You,")에만** 선택적으로 쓰고, 별도 글꼴 에셋이 없으면 `Arial` Bold로 대체한다. 한글 본문에는 절대 쓰지 않는다.
- 제목은 좌측 정렬이 기본. 중앙 정렬은 표지·섹션 슬라이드·마무리에만 허용.
- 한글은 글자 단위로 줄바꿈되므로 **카드 안 설명문은 `\n`으로 줄을 직접 끊고**, 한 줄 약 9–13자(12pt 기준 폭 1.5–2.3인치)를 넘기지 않는다.

## 4. 레이아웃 시스템 (16:9, 10" × 5.625")

`pres.layout = "LAYOUT_16x9"` 고정. 바깥 여백 최소 0.5", 블록 간격 0.3".

참고 덱에서 반복된 6가지 슬라이드 유형을 템플릿으로 정의한다. **내지 5장 이상이면 최소 3가지 유형을 섞는다.**

### A. 표지 (Cover) — 전면 빨강
- 배경 `RED` 전체.
- 좌상단: 로고 자리 (x 0.5, y 0.35, 약 1.4×0.5). 공식 로고 에셋이 없으면 텍스트 `[LOGO]` 대신 브랜드명을 흰색 Bold 14pt로.
- 메인 타이틀: x 0.8, y 1.7, 흰색 54–60pt Bold.
- 서브타이틀: 타이틀 아래 0.3", 흰색 16–18pt.
- 하단: **흰색 물결(웨이브) 곡선**이 가로로 가로지른다 (y ≈ 3.9–5.6). pptxgenjs는 곡선 도형이 제한적이므로 **SVG → PNG(`sharp`)로 만들어 `addImage`** 한다.
- 우측: 제품 사진(병·캔 등)이 슬라이드 경계를 살짝 넘는 느낌으로 크게 배치 (x ≈ 6.0–9.8, 높이 4.5"+). 사진 에셋이 없으면 흰 원 + 아이콘으로 대체.

### B. 소개/인물형 — 흰 바탕 + 하프 블리드 사진
- 한쪽 절반(좌 또는 우, 폭 약 4.5")을 사진으로 꽉 채움.
- 반대쪽에 제목(빨강 Bold) + 짧은 본문(12–14pt) + 하단 코너에 빨강 블록.
- 좌우를 번갈아 배치해 리듬을 만든다.

### C. 본문 텍스트형 — 흰 바탕 + 소제목 목록
- 제목 좌상단, 소제목(Bold)+설명 2–4개 항목, 한쪽에 사진 또는 아이콘 열.
- 소제목은 `RED` Bold + 한 줄 설명으로 "Label: 설명" 구조.

### D. 데이터/통계형 — 흰 바탕 + 하단 빨강 통계 바
- 상단: 제목 + 표 또는 차트(파이/도넛/라인).
- 하단: **전폭 빨강 바(y ≈ 4.3, h 1.0)** 안에 큰 수치 3–4개를 가로 배열 (흰색 30–40pt + 아래 10–11pt 라벨).
- 차트는 `addChart()` 네이티브만 사용. 색은 `RED` → `RED_DEEP` → `BLACK` → `GRAY_LINE` 순.

### E. 섹션/제품 소개형 — 전면 빨강 + 중앙 정렬
- 배경 `RED`, 제목 흰색 중앙, 부제 흰색 12–14pt.
- 하단에 제품/항목 3–4개를 아이콘 또는 사진 + 캡션으로 가로 배열.
- 4번째 이후 슬라이드마다 1장 정도 끼워 흰 슬라이드의 흐름을 끊는다.

### F. 마무리 (Closing) — 전면 빨강
- 큰 "Thank You," (영문 필기체 가능, 아니면 Bold) 흰색 중앙/좌측, 우측 사진.
- 선택: 마지막에 흰 바탕 연락처 슬라이드 1장 (SNS 아이콘은 빨강 원 안 흰 아이콘).

## 5. 장식 모티프 (참고 덱의 시그니처)

참고 이미지에서 거의 모든 내지에 반복된 요소들이다. **슬라이드당 1–2개만** 쓰고, 덱 전체에서 일관되게 반복한다.

| 모티프 | 모양 | pptxgenjs 구현 |
|--------|------|----------------|
| **코너 빨강 블록** | 슬라이드 모서리(주로 우하단/우상단)에 붙은 단색 사각형, 약 0.9×0.5" ~ 1.2×0.7" | `RECTANGLE`, fill `RED`, 가장자리 밖으로 나가지 않게 |
| **작은 검정 블록** | 빨강 블록 옆/아래의 얇은 검정 사각형, 약 0.5×0.12" | `RECTANGLE`, fill `BLACK` |
| **× 마커** | 모서리·여백에 떠 있는 작은 ×, 0.12–0.15" | 텍스트 "×" 또는 두 선 교차. 색 `RED` 또는 `BLACK` |
| **사선 해칭 패치** | 대각선 줄무늬 영역, 약 0.9×0.3" | pptxgenjs는 패턴 채움 미지원 → `LINE` 6–8개를 반복 배치하거나 PNG로 생성 |
| **점선 구분선** | 점(dot) 라인 | `LINE`, `dashType: "sysDot"`, 색 `GRAY_LINE` |
| **아이콘 원** | 빨강 원(지름 0.5–0.7") 안 흰 아이콘 | `react-icons` → `sharp` PNG, 원은 `OVAL` |

아이콘 원은 본문 항목(리스트, 카드)의 머리 표시로 쓴다. 아이콘은 반드시 **빨강 원 + 흰 아이콘** 또는 **흰 원 + 빨강 아이콘**의 고대비 조합.

## 6. 이미지/사진 규칙

- 제품·분위기 사진은 **채도 높고 대비가 강한 클로즈업**(물방울, 얼음, 병/캔). 흐릿하거나 저해상도 사진 금지.
- 사진은 **하프 블리드**(슬라이드 절반 꽉 채움) 또는 **경계 돌파**(표지의 병·캔)로 쓴다. 작은 썸네일을 나열하는 용도로는 쓰지 않는다.
- 사진이 들어가는 영역 위에는 텍스트를 올리지 않는다 (가독성). 올려야 한다면 단색 빨강 블록 위에 올린다.
- 모든 이미지는 프로젝트의 `assets/` 폴더에서 불러온다. 에셋이 없으면 **임의 URL 다운로드 없이** 도형·아이콘으로 대체하고 사용자에게 에셋 필요 여부를 알린다.
- 이미지에 `transparency`를 줄 때만 0–100 값을 쓴다 (hex 알파 금지).

## 7. 상표·저작권 주의

참고 덱은 실제 기업(Coca-Cola)의 상표·로고·제품 사진을 사용한다. 이 가이드라인은 **스타일(색 구성, 레이아웃, 모티프)** 만 빌려온 것이다.

- 코카콜라의 **공식 로고, 병/캔 사진, 필기체 로고 서체는 에셋으로 복제하지 않는다.** 사용자가 정식 사용 권한이 있는 파일을 `assets/`에 직접 넣었을 때만 사용한다.
- 다른 주제(예: AI Agent)의 덱에는 해당 주제에 맞는 자체 사진·아이콘을 쓰고, 이 스타일은 **색·구성만** 적용한다.
- 덱에 특정 기업을 사칭하는 문구나 로고를 넣지 않는다.

## 8. 스킬 기본 규칙과의 관계

`skills/pptx/SKILL.md`의 "Design Ideas / Avoid" 와 이 가이드가 다를 때는 **이 가이드를 따른다.** 단, 아래는 그대로 유지한다.

| SKILL.md 규칙 | 이 프로젝트에서의 처리 |
|---------------|-----------------------|
| 제목 아래 **강조 밑줄** 금지 | **그대로 금지.** 제목 밑줄 쓰지 않는다 |
| **슬라이드 폭 전체 헤더/푸터 바**, 가장자리 세로 줄무늬 금지 | **그대로 금지.** 단, 이 가이드의 **코너 블록**(모서리에 붙은 사각형)과 **하단 통계 바(D형, 데이터를 담는 용도)** 는 허용 |
| 카드 한쪽 가장자리 얇은 강조 테두리 금지 | **그대로 금지.** 카드 구분은 `RED_TINT` 배경이나 그림자로 |
| 베이지/크림 배경 금지 | 그대로. 배경은 `WHITE` 또는 `RED` |
| 기본 파랑 계열 지양 | 이 가이드의 팔레트(빨강·흰·검정)만 사용 |
| 안전 글꼴 사용 | `Malgun Gothic`(한글) + `Arial`/`Calibri`(영문) |
| 모든 슬라이드에 시각 요소 | 그대로. 사진·아이콘·차트·도형 중 최소 1개 |
| 텍스트 오버플로 금지, 가운데 정렬 본문 금지 | 그대로 |

## 9. 코드 스니펫 (pptxgenjs 시작 템플릿)

```js
const RED = "F40009", RED_DEEP = "B30000", RED_TINT = "FDECEC";
const WHITE = "FFFFFF", BLACK = "111111";
const GRAY_TEXT = "5F5F5F", GRAY_LIGHT = "F2F2F2", GRAY_LINE = "D9D9D9";
const FONT_KO = "Malgun Gothic", FONT_EN = "Arial";

pres.layout = "LAYOUT_16x9"; // 10 x 5.625

// 코너 빨강 블록 + 작은 검정 블록 (우하단)
function cornerBlock(slide, pres) {
  slide.addShape(pres.shapes.RECTANGLE, { x: 8.6, y: 5.05, w: 1.4, h: 0.575, fill: { color: RED }, line: { color: RED } });
  slide.addShape(pres.shapes.RECTANGLE, { x: 8.0, y: 5.45, w: 0.5, h: 0.12, fill: { color: BLACK }, line: { color: BLACK } });
}

// × 마커
function xMark(slide, x, y, color = RED) {
  slide.addText("×", { x, y, w: 0.2, h: 0.2, fontFace: FONT_EN, fontSize: 12, bold: true, color, margin: 0, align: "center", valign: "middle" });
}

// 하단 통계 바 (D형)
function statBar(slide, pres, stats /* [{value,label}] */) {
  slide.addShape(pres.shapes.RECTANGLE, { x: 0, y: 4.3, w: 10, h: 1.325, fill: { color: RED }, line: { color: RED } });
  const w = 10 / stats.length;
  stats.forEach((s, i) => {
    slide.addText(s.value, { x: i * w, y: 4.4, w, h: 0.6, fontFace: FONT_EN, fontSize: 34, bold: true, color: WHITE, align: "center", margin: 0 });
    slide.addText(s.label, { x: i * w, y: 5.0, w, h: 0.4, fontFace: FONT_KO, fontSize: 11, color: WHITE, align: "center", margin: 0 });
  });
}
```

> 주의: `shadow` 같은 옵션 객체는 pptxgenjs가 내부에서 변형하므로 **호출마다 새로 만든다.**

## 10. 슬라이드 완성 체크리스트

- [ ] 색은 토큰 팔레트(빨강/흰/검정/회색)만 썼는가?
- [ ] 슬라이드당 빨강 "주인공"이 1곳인가? 빨강 배경 위 텍스트는 전부 흰색인가?
- [ ] 6가지 유형 중 3가지 이상을 섞었는가? (5장 이상 덱 기준) 표지/마무리는 전면 빨강인가?
- [ ] 모든 슬라이드에 사진·아이콘·차트·도형 중 시각 요소가 있는가?
- [ ] 장식 모티프는 슬라이드당 1–2개이고 덱 전체에서 같은 방식으로 반복되는가?
- [ ] 제목 밑줄·전폭 헤더바·가장자리 줄무늬가 없는가?
- [ ] 한글 줄바꿈이 어색하게 끊기지 않는가 (`\n`으로 직접 줄바꿈)?
- [ ] 공식 로고·제품 사진을 권한 없이 쓰지 않았는가?
- [ ] `validate.py` 통과 + PowerPoint 렌더링으로 모든 슬라이드를 눈으로 확인했는가?
